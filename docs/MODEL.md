# 台阶式上涨数学模型说明

模型把台阶式上涨拆成四个阶段循环：**上涨 → 回调 → 横盘 → 再突破**。系统先判断当前处于哪个阶段，再用评分模型估算明日上涨概率和波动区间。实现位于 `backend/app/services/feature_service.py`（特征）与 `prediction_service.py`（分类/评分/回测）。

模型至少需要 20 个交易日数据；不足 20 天时只按 5 日涨幅做简单趋势判断。

## 1. 特征计算

| 特征 | 公式 |
| --- | --- |
| 日涨跌幅 | `(今收 - 昨收) / 昨收 × 100%` |
| 趋势强度 | `trend_return_N = (今收 - N日前收盘) / N日前收盘 × 100%`，N = 5/10/20 |
| 回调幅度 | `drawdown = (今收 - 近20日最高价) / 近20日最高价 × 100%` |
| 箱体振幅 | `box_range = (近5日最高 - 近5日最低) / 近5日最低 × 100%` |
| 量比 | `volume_ratio = 今日成交量 / 20日均量` |
| 均线 | MA5 / MA10 / MA20，5日均量 / 20日均量 |
| 突破 | 收盘价 > 之前 5 日（或 10 日）最高价 |
| 假突破 | 昨收突破前 5 日高点，今收又跌回突破位之下 |
| 长上影线 | 上影线 > 实体 × 2 且上影线占收盘价 > 1.5% |
| 波动基础 | `avg_abs_return = 近20日 |日涨跌幅| 的均值` |
| 支撑 / 压力 | 近 10 日最低价 / 近 20 日最高价 |

## 2. 状态分类（按优先级）

1. **突破阶段**：收盘价突破之前 5 日高点，且量比 > 1.3，且价格在 MA5、MA10 之上。
2. **风险阶段**：以下信号满足任意 2 条 —— 高位（10日涨幅>10%）放量下跌、长上影线、跌破 MA10、跌破 MA20、20日涨幅>25% 且量比>2。
3. **健康回调**：10 日涨幅 > 10%，回调 3%~8%，量比 < 1.2，价格仍在 MA20 之上。
4. **横盘整理**：近 5 日箱体振幅 < 6%，量比 < 1，价格距 MA5 不超过 3%。
5. **上涨阶段**：5 日涨幅 > 6%，价格在 MA5、MA10 之上。
6. 以上都不满足：**震荡观察**。

## 3. 评分模型（-100 ~ +100）

| 类别 | 条件 | 分数 |
| --- | --- | --- |
| 趋势 | 5日涨幅 > 5% | +15 |
| 趋势 | 10日涨幅 > 10% | +15 |
| 趋势 | 价格在 MA5 上 / 下 | +10 / -10 |
| 趋势 | 价格在 MA10 上 / 下 | +10 / -10 |
| 回调 | 回调 3%~8% 且缩量（量比<1.2） | +15 |
| 回调 | 回调超过 12% | -20 |
| 回调 | 10日涨幅>15% 且几乎无回调（高位连续上涨） | -10 |
| 量能 | 上涨放量（量比>1.5） | +15 |
| 量能 | 横盘缩量（量比<0.8） | +10 |
| 量能 | 下跌缩量（量比<0.7） | +8 |
| 量能 | 下跌放量（量比>1.5） | -20 |
| 突破 | 突破最近10日高点（不与5日叠加） | +30 |
| 突破 | 突破最近5日高点 | +20 |
| 突破 | 假突破后回落 | -25 |
| 风险 | 长上影线 | -15 |
| 风险 | 高位放量阴线 | -30 |
| 风险 | 跌破 MA20 | -25 |
| 状态 | 判定为风险阶段 | -30 |

总分截断到 [-100, 100]。

## 4. 概率转换

```
上涨概率 = 50% + score × 0.35     （限制在 10% ~ 90%）
下跌概率 = 100% - 上涨概率
```

例：score = 40 → 上涨概率 64%，下跌概率 36%。

## 5. 涨跌幅区间

基础区间为近 20 日平均绝对涨跌幅 `avg_abs_return`，按状态修正：

| 状态 | 上涨区间系数 | 下跌区间系数 |
| --- | --- | --- |
| 上涨阶段 | 1.2 | 0.8 |
| 健康回调 | 0.8 | 1.2 |
| 横盘整理 | 0.7 | 0.7 |
| 突破阶段 | 1.5 | 1.0 |
| 风险阶段 | 0.6 | 1.5 |
| 震荡观察 | 1.0 | 1.0 |

输出形如 `预计上涨幅度: 0% ~ 3.8%`、`预计下跌幅度: 0% ~ -2.4%`。

## 6. 回测方法

滚动窗口：用第 1~N 天预测第 N+1 天，窗口每次向后滑一天。预测方向（上涨概率≥50% 记为看涨）与次日实际涨跌比对，统计：

- 总预测次数、正确次数、错误次数、准确率
- 平均预测上涨概率、实际平均涨跌幅
- 最大错误案例（方向错且实际波动最大的 5 次）

## 7. 模型局限

- 纯技术面统计规则，无法预测突发利好/利空、政策、停复牌与市场情绪。
- 评分权重为人工设定，未经大样本优化；不同股票、不同市场环境下表现差异很大。
- 上涨概率只是分数的线性映射，并非真实统计概率，使用前请先用回测接口验证。
